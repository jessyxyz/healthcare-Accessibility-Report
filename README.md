# Healthcare Accessibility Report

This project analyzes disparities in healthcare access across urban and rural regions in Africa, using Power BI for data visualization.

## 📊 Project Highlights

- **Data Source:** Healthcare facility dataset with patient visits, funding, staffing, etc.
- **Tool Used:** Power BI
- **Key Insights:**
  - Urban areas have over double the number of healthcare professionals compared to rural regions.
  - Rural regions face challenges in emergency response time and infrastructure.
  - Funding allocation is aligned with population split but not with healthcare needs.

## 📁 Files Included

- `PROJECT REPORT(POWERBI).pdf`: Detailed report with analysis and recommendations.
- `Healthcare_Access_Africa.csv`: Raw dataset used in Power BI.
